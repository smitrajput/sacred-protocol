# Glossary

These words are used the same way everywhere in Sacred.

## Products

| Word | Meaning |
| --- | --- |
| **Earn** | Depositing USDC in the MarginVault to receive a share of Trade's markup |
| **Trade** | Buying BTC or ETH with your capital plus financing, at a fixed price. The contracts call this margin |
| **Borrow** | Receiving USDC against collateral through a fixed-price sale. The contracts call this Cash Finance |
| **MarginVault** | The pool that funds Trade |
| **CashFinanceVault** | The separate pool that funds Borrow |
| **Available** | Funds in your account that are not in a product |

## Sale terms

| Word | Meaning |
| --- | --- |
| **Financed APR** | The annualized quoting convention for markup: 10% at 2×. What you agree to is a dollar price |
| **Fixed markup** | The seller's profit, fixed at the sale: `financing × APR × days ÷ 365` |
| **Financing** | The part of the purchase not paid by the trader: `asset cost × (1 − 1/leverage)` |
| **Leverage** | Asset purchase cost divided by the trader's capital |
| **Full debt** | Everything remaining under the sale, including scheduled markup |
| **Partial sale** | A sale of only enough pledged asset to restore coverage |
| **Coverage** | Trade: asset value divided by full remaining debt |
| **Debt LTV** | Borrow: full remaining debt divided by collateral value |
| **Principal LTV** | Borrow: USDC principal divided by collateral value. 45% at entry |
| **Rebate** | A waiver of unearned markup on early settlement. Binding in Borrow if approved |
| **Principal shortfall** | The part of financing not recovered. Recorded even if a reserve absorbs it |
| **Pledge** | The asset held as security. It belongs to the buyer |

## Vaults and protection

| Word | Meaning |
| --- | --- |
| **Depositor** | Someone with USDC in Earn. Research documents call them an LP |
| **Investor** | Someone with USDC committed to Funding Borrow |
| **Active NAV** | The value of the vault, idle cash and financed positions, less recognized impairment |
| **Utilization** | Productive financing divided by active NAV |
| **Approved capacity** | Financing authorized, including commitments. Protection is measured against this |
| **Vintage** | A group of deposits or commitments with the same fixed terms |
| **Conservation terms** | A 70% base share offered to consenting new Earn vintages when use is weak |
| **Primary and tail stock** | Earned manager cash set aside for losses in Trade. Targets 0.4% and 0.6% of approved financing at 2× |
| **Pilot backstop** | The fourth layer of protection: a small portion of the capital Sacred raises from investors, set aside to protect the pilot phase of Earn and Borrow |
| **Company cash** | Operating runway. It is neither credit protection nor depositor money |
| **Investment risk reserve (IRR)** | Borrow's reserve, owned by investors and funded from their profit |
| **Loss carry** | Losses that future earnings must restore before profit is shared |
| **Manager** | Sacred, running the vaults |
| **Keeper** | A process that triggers checkpoints, reviews and sales. Anyone can run one |

## SIFT

| Word | Meaning |
| --- | --- |
| **SIFT** | Skill-Informed Financing Tiers: how financing capacity follows real results |
| **Curve ceiling** | C(q): the published financing ceiling after `q` qualifying funded days, from $500 to $100,000 |
| **Qualifying funded day** | One complete 24-hour funded period that meets the use, rolling-result, drawdown, data and contribution tests |
| **Repayment checkpoint** | Evidence required every 14 qualifying days: full-term repaid principal and positive contribution |
| **Headroom** | What is left of the effective ceiling after outstanding and pending financing |
| **Starter, Serviced** | Before and after the first successful repayment checkpoint |
| **Proven** | A separate long-window skill label. It can improve ranking and is not required for any milestone |
| **Earned ceiling** | The financing an account has earned through reviews |
| **Sticky risk ceiling** | A lower limit left by a drawdown. No automatic recovery in v1 |
| **Headroom** | Ceiling minus outstanding and pending financing |
| **Fresh capital** | Settled, unpledged capital available for a new position |
| **Unit NAV** | Account performance with deposits and withdrawals stripped out |
| **Excess return** | Account return above frozen BTC and ETH exposure |
| **Effective observations** | Weekly observations after correlation is discounted |
| **SIFT score** | Shrunk excess return less an uncertainty haircut. Not a probability |
| **Contribution (J)** | Collected markup less losses and variable costs, per contractual financed dollar-day |
| **Discovery** | The bounded first pilot, where newcomers may fill the whole envelope |

## Islamic finance

| Word | Meaning |
| --- | --- |
| **Mudarabah** | One side gives capital, the other manages it. Profit is split by ratio; capital bears loss |
| **Murabaha** | A sale at disclosed cost plus an agreed profit, payable later |
| **Musawamah** | A sale at a negotiated price, without disclosing cost |
| **Rahn** | A pledge securing a debt. Surplus on sale returns to the owner |
| **Riba** | Interest, or any increase charged for delay |
| **Qard** | A loan. Any stipulated excess is prohibited |
| **Qabd** | Possession |
| **Ibra'** | A waiver of part of a debt |
| **Tawarruq** | Buying a commodity on credit to sell for cash. Organized forms are restricted |
| **Salam** | A prepaid forward sale. Not in this design |
