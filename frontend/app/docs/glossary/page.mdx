# Glossary

These words are used the same way everywhere in Sacred.

| Word | Meaning |
| --- | --- |
| **Ticket** | One financed purchase of one coin by one trader. Each ticket holds its own coin and its own debt |
| **Bucket** | A separate pool of USDC in the vault, for one coin and one mode. Buckets never share money or losses |
| **Down payment** | The USDC the trader pays when the ticket opens. The first part of the price, and the trader's maximum loss |
| **Cost** | What the vault actually paid for the coin, swap fees included |
| **Markup** | The vault's fixed profit on the sale, set when the ticket opens. It never grows. It is the depositors' yield |
| **Sale price** | Cost plus markup |
| **Balance** | Sale price minus the down payment. The trader owes it by the due date. It can only go down |
| **Financed amount** | Cost minus the down payment: the vault's money at work in the ticket |
| **Leverage** | Cost divided by the down payment. 1,000 USDC down at 3x buys 3,000 of coin |
| **Due date** | The fixed date by which the balance must be paid |
| **Pledge** | The coin, held in the ticket as security for the balance. It belongs to the trader |
| **Settlement amount** | What closes the ticket today: the balance, less any markup waived for paying early |
| **Early-settlement waiver** | Markup × days left ÷ term, not charged to a trader who closes or pays off early. Vault policy, not a term of the sale |
| **Shortfall** | The gap when the coin is sold for less than the balance |
| **Limited recourse** | The vault can collect only from the pledged coin. It absorbs any shortfall |
| **Cover** | Margin and evergreen modes. The coin's market value divided by the settlement amount |
| **Forced sale** | Margin and evergreen modes. A sale of only enough coin to restore cover when it falls to the sale level |
| **Term mode** | 7 or 14 day tickets never sold before the due date. The mode that is built |
| **Margin mode** | Tickets up to 30 days with a forced partial sale at low cover. Waits for a board ruling |
| **Evergreen** | A margin ticket with a 365-day term, charged only for days held, sold only at 110% cover |
| **Cut-off** | The weekly moment when vault shares are priced and queued deposits and withdrawals are processed |
| **Share price** | The value of a bucket divided by its shares, computed at each cut-off |
| **Loss reserve** | A slice of markup kept in each bucket, outside the share price, that pays shortfalls first |
| **Backstop fund** | USDC and staked SCR that pay shortfalls after the loss reserve. Fed by 30% of trader profit |
| **Liquidity reserve** | USDC that deposits into a bucket short of cash for its withdrawal queue. Built by selling SCR |
| **Reserve sale** | The sale of new SCR for USDC into the liquidity reserve, delivered staked |
| **Keeper** | A server that settles due tickets and runs the cut-off. Anyone can do both; it is paid actual cost |
| **Points** | One per USDC of markup paid, or per USDC per day deposited. A discretionary gift that promises nothing |
| **Mudarabah** | A partnership where one side gives capital and the other manages it. Profit is split by an agreed ratio; loss of capital falls on the capital provider |
| **Murabaha** | A sale at disclosed cost plus an agreed profit. The price may be paid later, but it is fixed at the sale |
| **Rahn** | A pledge that secures a debt. If the debt is unpaid, the pledge is sold and any surplus returns to its owner |
| **Riba** | Interest, or any increase charged for delay. What the design is built to avoid |
| **Qabd** | Possession. Whether the vault's ownership within one transaction counts is an open ruling |
| **Ibra'** | A creditor's waiver of part of a debt. How the early-settlement waiver is understood |
| **Takaful** | A mutual fund in which members cover each other's losses. The fallback if limited recourse is refused |
| **Salam** | A prepaid forward sale. The only classical route to a short, and not in this design |
| **'Urbun** | A down-payment sale where the deposit is forfeited. Not this design: nothing is forfeited |
